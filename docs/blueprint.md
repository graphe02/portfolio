# **App Name**: Personal Showcase

## Core Features:

- Guitar Video Gallery: Display of categorized guitar videos sourced from YouTube (via API).
- Guitar Tablature Display: Display of guitar tablature.
- Coding Project Showcase: Showcase of coding projects with optional demos. Description for each project.
- Gaming Video Gallery: Display of gaming videos sourced from YouTube (via API).
- Content Tagging: Ability to filter the video or code lists by tags.

## Style Guidelines:

- Primary color: Black to represent creativity and sophistication.
- Background color: White. It's subtly tinted with the primary hue for harmony but desaturated to keep it clean and unobtrusive.
- Accent color: dark Wood texture. It stands out from the primary while maintaining a sense of continuity. Use for highlights and calls to action.
- Body and headline font: 'Helvetica', modern look and feel. A great fit for both headlines and body text.
- Use simple, line-based icons for categories and interactive elements.
- A clean, grid-based layout with generous white space to allow content to breathe. Prioritize readability.
- Subtle transitions and animations on hover or when loading content. Keep animations minimal to avoid distracting from the content.
