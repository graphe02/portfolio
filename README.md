# Portfolio

Personal portfolio website built with Next.js.

## Quick Start

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`

## Commands

```bash
npm run dev              # Development server
npm run build            # Build for production
npm run start            # Start production server
npm run generate-data    # Update RSS feeds
```

## Structure

- **About** - Personal info and social links
- **Guitar** - Video covers and tablature editor
- **Projects** - Coding projects showcase
- **Gaming** - Gaming content and highlights

## Deployment

```bash
npm run build
npm start
```

Built with Next.js, TypeScript, and Tailwind CSS.
