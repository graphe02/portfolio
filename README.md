# lifeunderday

A personal portfolio website showcasing projects, guitar content, and more.

## Features

- **About** - Personal introduction and social links
- **lifeunderday** - Life under day content
- **Guitar** - Guitar videos and tablatures
- **Projects** - Coding projects and experiments
- **Eyes of the World** - View counter page
- **WIP** - Work in progress items

## Tech Stack

- **Framework**: Next.js 15 with App Router
- **Styling**: Tailwind CSS with shadcn/ui components
- **Database**: SQLite for visitor tracking
- **Deployment**: Vercel-ready

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Scripts

- `npm run grab-guitar` - Fetch latest guitar videos from YouTube RSS
- `npm run generate-data` - Generate sample data files

## Environment Variables

- `YOUTUBE_API_KEY` - Optional YouTube API key for enhanced video data
